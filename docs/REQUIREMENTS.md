# Han Bridge CRM System

Создай полноценную web CRM/ERP систему для языковой школы Han Bridge.

Основное направление школы:

* Китайский язык
* Английский язык

Сейчас учет ведется в Excel, поэтому система должна полностью заменить Excel и предоставить современный интерфейс для управления школой.

---

# Общие требования

Система должна быть построена как полноценное веб-приложение.

Frontend:

* Next.js 15
* TypeScript
* Tailwind CSS
* ShadCN UI
* Responsive Design
* Light/Dark Theme

Backend:

* NestJS
* TypeScript
* REST API
* Swagger

База данных:

* PostgreSQL
* Prisma ORM

Инфраструктура:

* Docker
* Docker Compose
* Персистентное хранение данных через Docker Volumes
* После перезагрузки сервера все данные должны сохраняться
* Возможность быстрого резервного копирования базы данных

Авторизация:

* JWT
* RBAC
* Роли пользователей
